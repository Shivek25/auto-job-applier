# Formatting Rule: No Em Dashes

Never use em dashes (— or \u2014 or &mdash;) anywhere in any generated content, resumes, website UI, templates, logs, documentation, or assistant responses.
Instead of an em dash:
- Use standard hyphens (-) or spaced hyphens ( - )
- Use colons (:)
- Use commas (,)
- Use parentheses
